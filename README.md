# 为革命 · 天下为公

**FOR REVOLUTION · THE WORLD BELONGS TO ALL**

一部可运行、可静态部署的孙中山革命生涯沉浸式艺术作品。观众在同一张 Three.js Canvas 中穿行十六个空间，经历问路、革命、共和、挫折与未竟的公共理想。自动观影为240秒；也可以滚动、拖动、触屏或选择章节自由探索。

## 运行

需要 Node.js 22.12+（本项目使用 Node.js 24 验证）。在项目目录执行：

```bash
npm install
npm run dev
```

打开终端显示的地址，默认 `http://127.0.0.1:5173`。

- 完整自动观影：`http://127.0.0.1:5173/?cinematic=true`
- 某一章节：`http://127.0.0.1:5173/?chapter=exile`
- 指定片中时间：`http://127.0.0.1:5173/?t=130`
- 英文界面：`http://127.0.0.1:5173/?lang=en`

自动观影链接可直接开始画面。浏览器要求声音由用户点击解锁；右上角声音按钮可开启本地中文旁白与环境声。通过“进入作品”或“观看完整影片”按钮进入时，同时请求解锁声音。

## 操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 / 画面拖动 / 手指滑动 | 自由推进或回到前面的历史空间 |
| 底部进度条 | 精确定位片中时间 |
| 播放键 / 空格 | 播放或暂停；影片结束后重新播放 |
| 方向键 / 前后章按钮 | 跳转历史空间 |
| 章节菜单 | 选择十六个世界 |
| 史料与创作 | 阅读当前章节语境、史实与影像出处 |
| 南京场景的“靠近约法” | 放大阅读第二条、第五条的中英节选，并查看原始出处 |
| Esc | 关闭抽屉并返回作品 |
| 中 / EN | 切换界面语言，保留中英双语字幕与中文叙述 |
| 声音 / 麦克风图标 | 分别控制全部声音与中文旁白 |
| 天下为公字标 | 回到封面 |

移动端自动降低像素比、抗锯齿与粒子数量；无需电脑才能体验。设备的“减少动态效果”设置会减少交互镜头漂移及界面动效。切到后台时暂停影片，回到前台后按原状态继续。

## 构建与部署

```bash
npm run build
npm run preview
```

`dist/` 是完整的静态发布目录，包含影像、字体、数据与29段预生成中文旁白。可上传到任意支持静态文件的服务器、Nginx、GitHub Pages或静态托管平台。Vite使用相对基础路径 `./`，支持放在站点子目录；查询参数由同一个 `index.html` 处理，不需要后端或商业地图API。

不要直接双击 `index.html` 使用 `file://` 打开：ES模块、JSON与音频需要通过HTTP提供。正常运行和部署不需要Python、语音服务、第三方字体CDN、外部图片站或密钥。

## 史料与创作边界

关键史实、具体日期、出处与语境收录在 `content/timeline.json`；应用内可直接阅读。孙中山并未在武昌现场亲自指挥起义；作品明确呈现其当时在美国，并呈现新军、革命组织、华侨与不同社会力量。北上列车对应天津至北京末段，不把海陆混合旅途写成全程铁路。

建筑、纸张、海洋、人物剪影、脉搏、碎裂和声音是艺术表达；不冒充历史现场的精确复原。原始历史照片与题词均有可追溯的档案记录，详见 [ATTRIBUTION.md](./ATTRIBUTION.md)。未采用来源不明的原有JFIF文件。未使用AI生成历史照片。

“天下為公”墨迹直接分割自1924年手迹；四字横向重排是公开说明的艺术衍生。原件、透明蒙版、有符号距离场和80,000个墨迹采样点保留在 `public/assets/archive/`。渲染按设备选用采样点子集，保持触屏与移动设备的性能。黑色镜面使用WebGL反射与抽象后来人轮廓，不调用摄像头。

南京的约法阅读保留条次和1912年3月11日的日期，只展示短节选。中文按史料转写为简体，英文为本作品的现代译文；不把法条所表达的理想等同于当时已经实现的政治实践。

旁白为当代合成叙述者，已保存为本地MP3，不是孙中山原声或声音克隆。只有遗嘱中注明出处的短句作为历史引语；其他诗性旁白为本作品的叙述。程序环境声是原创艺术设计。

黄花岗花瓣段（片中01:44–01:50）保留完整静默，暂停环境声与旁白，仅以双语字幕呈现，随后进入武昌的消息与声音。

## 项目结构

```text
src/
  core/              连续世界、镜头、资源复用与渲染
  scenes/            十六个世界与空间物件
  shaders/           墨迹、暗房显影、烧纸、海面、颗粒与转场
  content/           章节、时间与中英字幕
  archive/           可发布素材清单
  audio/             Web Audio环境声与本地旁白同步
  main.ts            交互、播放、章节与资料抽屉
  style.css          编辑式界面、触屏与响应式布局
content/             史实原始索引
public/assets/
  archive/           历史影像、海岸数据与手迹衍生
  audio/             29段本地中文MP3和时长清单
  fonts/             本地OFL字体与许可文本
scripts/             内容验证、素材处理和可选再生成工具
artifacts/           实际浏览器截图与验收记录
```

## 验证与可选素材再生成

```bash
node scripts/verify-content.mjs
npm run build
```

内容验证检查连续240秒、所有字幕和音轨的时间窗口、双语字段、史实关联、武昌的海外语境、档案文件散列、许可记录、GeoJSON与书法采样。浏览器验收记录保存在 `artifacts/VERIFICATION.md`，截图同目录。

素材已随项目准备好。需要重新下载或改写旁白时，以下Python工具可选使用：

```bash
python -m pip install requests pillow numpy scipy fonttools brotli edge-tts mutagen
python scripts/prepare_archive.py
python scripts/prepare_calligraphy.py
python scripts/prepare_fonts.py
python scripts/prepare_audio.py
python scripts/write_attribution.py
node scripts/prepare_runtime_notices.mjs
```

下载工具接受可选的 `--proxy` 参数，但不会保存代理配置。音轨再生成需要网络，正常播放不需要。修改章节文本后，重新生成音轨、字体子集并执行内容验证。历史图像或来源变动时，同步更新素材清单和授权记录。
